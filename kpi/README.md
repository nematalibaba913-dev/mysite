# DOST Evi · Təlimçilərin KPI qiymətləndirmə sistemi

Statik veb tətbiq (GitHub Pages) + Supabase (verilənlər bazası, giriş, RLS).

- **Mütəxəssis** — ortaq şifrə ilə daxil olur, ad/vəzifəni yazır, hər təlimçini ayrıca qiymətləndirir.
- **Direktor (moderator)** — bütün blankları görür, özü qiymətləndirir, ortalama balı canlı görür.
- **Admin** — nəticələr, təqdimat (veb + PowerPoint), təhlil paneli, blanklar, təlimçilər, rüblər, şifrələr.

Hesablama Excel blankının düsturları ilə eynidir (Bal = Nəticə % × Maks. bal; yaradıcılıq — səviyyə üzrə bal).
Yekun bal — bütün qiymətləndiricilərin bərabər çəkili ortalaması.
